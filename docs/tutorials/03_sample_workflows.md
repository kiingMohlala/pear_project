# Sample workflows

## Finance monthly review
1. Import statements (FinanceAgent / files)
2. Categorize transactions
3. Summarize spend by category
4. Optional: Slack notify (approval required)

## Contract → executive summary
1. Ingest PDF/DOCX into KnowledgeStore
2. LegalAgent clause extraction
3. Collaboration reviewer pass
4. Store summary note

## Research brief
1. ResearchAgent multi-source gather
2. Rank sources
3. Produce cited summary
4. Optional: Notion page dry-run
