# PEAR User Guide (v3.00)

## Defaults

- CLI: `python -m ui.app`
- Web: `http://localhost:8080/dashboard`
- Login: `demo` / `demo` (change in production)

## Common commands

```text
note: buy milk
/agenda
/goals
/goal-create research X; then summarize
/collaborate review this summary
/workers
/backup
/diagnostics
```

## Upload & analysis

Ask PEAR to summarize a PDF/DOCX path, or use finance/legal agents for statements and contracts.

## Safety

Sensitive actions (email send, destructive desktop ops) may require approval. Use `/permissions` and connector auth status as needed.
